# Shiro Noir (Pet Concept)

This pet is inspired by the provided reference image:
- silver hair / cool gray palette
- wolf-like ear silhouette
- teal-blue rune halo motif
- elegant dark dress movement translated into flowing tail-ribbon motion

## Personality
- Quiet, observant, and protective
- Moves smoothly with low, floating energy
- Reacts with subtle teal glows instead of exaggerated motions

## Visual Spec
- **Primary colors:** charcoal `#1d2533`, silver `#cfd3df`
- **Accent colors:** teal `#5ca3aa`, ice `#a8c9d9`
- **Eyes:** cyan-teal with narrow sleepy shape
- **Silhouette:** small wolf-fox body + oversized fluffy tail + two rune rings above head

## Animation Direction (9 rows, 8 cols sheet)
1. Idle: breathing + tail sway
2. Run right: short sprint with trailing ribbon
3. Run left: mirrored sprint
4. Wave: front paw wave + halo pulse
5. Jump: compact leap + landing dust sparkle
6. Fail: ear droop + ring flicker out/in
7. Wait: seated curl + slow blink
8. Run: playful dash loop
9. Review: tiny notebook pop-up + proud nod
