# 和纸墨影：正式设计方向

## 定位与比例

本项目是独立图片展示系统，图片浏览、发现和查看详情是首要目标；内容审计只使用仓库与接口真实提供的能力。正式方向采用 B「和纸墨影」，视觉权重冻结为：

- 65% 现代图片画廊：清晰网格、中性图片舞台、明确交互状态和高效信息层级。
- 25% 古典日式空间秩序：留白、细分隔线、克制的不对称、低饱和自然色与衬线标题。
- 10% 现代日本都市氛围：仅以夜蓝、低饱和青色和少量朱砂强调表达。

## 最终设计原则

1. 图片始终是视觉主角；容器、文字和控件不得干扰图片色彩与比例判断。
2. 以留白、比例、分隔和材质感表达日式秩序，不堆砌符号、日文或传统图案。
3. 使用现代网格和清晰状态完成高效浏览；触屏、鼠标和键盘必须获得等效操作。
4. 默认表面保持平整，阴影只用于浮层和对话框，圆角只用于需要表达边界或可点击性的组件。
5. 朱砂只用于关键动作和必要强调，都市夜蓝只用于辅助层级；状态不能仅依赖颜色。
6. 不虚构字段、权限、缩略图、图集或审计能力；数据缺失时显示诚实的空缺或省略该区域。
7. 动效只说明状态变化，使用短时长且支持 reduced-motion；不使用装饰性漂移、发光或电影转场。

## 页面信息架构与现有路由

现有路由地址保持冻结，不新增后端未支持的业务入口：

| 路由 | 页面职责 | 说明 |
| --- | --- | --- |
| `/` | 入口重定向 | 保持重定向到 `/home` |
| `/square` | 公共图片发现与画廊 | 承担首页发现与公共画廊，不新增重复首页路由 |
| `/home` | 登录用户图片管理 | 保留上传、编辑、删除等现有能力 |
| `/image/:uuid` | 图片详情 | 展示真实返回的图片、作者/来源及元数据 |
| `/profile/:uuid` | 用户资料与图片 | 保留现有资料和资源轮询能力 |
| `/login`、`/register` | 认证入口 | 不删减现有密码、邮箱验证码和第三方登录流程 |
| `/403` | 权限/域名拒绝 | 保留明确的访问拒绝反馈 |
| `/admin/audit-log` | 管理员审计日志 | 保留现有管理员、域名和后端接口约束 |

“图集/专题”只在后端存在真实数据与路由需求后进入扩展阶段；当前不得伪造。沉浸式查看器是覆盖当前页面的应用级浮层，不占用新路由。

## 核心页面结构

- `/square`：主导航 → 发现标题区 → 搜索/筛选（现有能力）→ 主画廊 → 分页/加载状态。
- `/home`：主导航 → 页面标题与上传入口 → 已有筛选/管理工具 → 用户图片列表 → 分页与业务弹窗。
- 图集页：当前不建立独立路由；若未来后端支持，结构为图集说明 → 图片集合 → 分页。
- `/image/:uuid`：中性图片舞台 → 基本标题与作者信息 → 描述/标签 → 可折叠专业元数据 → 评论等现有能力。
- 查看器：中性深色遮罩 → 图片舞台 → 弱化的上一张/下一张与缩放控件 → 可开合信息面板。

## 冻结与可调整

冻结：65:25:10 比例、色彩角色、字体策略、语义间距、路由地址、图片 contain 原则、查看器中性深色、状态可访问性、无大型 UI/状态库、无接口和权限语义修改。

可在实现阶段按真实内容调整：单个断点附近的像素值、非业务文案、局部间距一档、移动端控件排列、既有页面迁移先后。任何调整不得改变视觉方向或数据含义。
